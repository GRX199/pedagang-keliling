# Audit 15 Oktober 2026

Pemeriksaan ini mencakup build aplikasi, alur pickup dan COD, chat, halaman publik pada ukuran HP/laptop, dependensi, serta pemeriksaan awal backend. Tidak ada perubahan skema database atau migrasi tambahan pada pembaruan ini.

## Perbaikan

- Chat tidak membuat ulang subscription setiap aktivitas percakapan. Hasil pemuatan awal digabungkan agar tidak menghapus pesan yang baru dikirim ketika koneksi lambat.
- Setiap percakapan memiliki state form sendiri. Saat berpindah chat, pesan, draft, dan preview percakapan sebelumnya tidak terbawa.
- Pengiriman pesan/foto memiliki pengunci langsung untuk mencegah Enter berulang mengirim dua kali. Form terkunci selama pengiriman; Enter saat komposisi keyboard tidak mengirim pesan.
- Polling mencakup batas timestamp terakhir dan menyaring ID yang sudah diterima, agar pesan dengan waktu sama tidak terlewat atau tampil ganda.
- Auto-scroll hanya menggerakkan daftar pesan. Pengguna yang sedang membaca pesan lama tidak dipaksa turun oleh pesan masuk.
- Tracking mempertahankan marker yang masih segar ketika pemuatan gagal sementara. Aksi progres dinonaktifkan jika data pesanan belum dapat diperbarui; kegagalan membaca ulasan tidak memblokir transaksi. Aturan kedaluwarsa lokasi tetap berlaku.
- Instruksi menunggu hanya ditampilkan kepada pelanggan. Pedagang melihat instruksi menerima, menyiapkan, dan menyelesaikan pesanan. Nama tombol penerimaan menjadi Terima pesanan. Informasi pengambil dipindahkan ke progres utama agar panel pedagang lebih ringkas.
- Lockfile backend diperbarui ke ip-address 10.7.4 dan proxy-addr 2.0.8. Patch alat development yang tersedia tanpa perubahan mayor juga diterapkan, termasuk Vitest 4.1.11.
- Tujuh temuan pada rantai Tailwind 3 diselesaikan dengan Tailwind 4.3.3 dan plugin Vite resmi. Sumber kelas ditentukan dari `src` dan `index.html`. Pengaturan border, bayangan, ring, dan lapisan CSS disesuaikan untuk mempertahankan tampilan.
- Nodemon beserta dependensi watcher lama dihapus dari backend. Perintah `npm run dev` memakai `node --watch app.js`, tanpa paket tambahan. Gunakan Node.js 22.12 atau lebih baru untuk lingkungan pengembangan proyek.
- Tombol ringkasan melayang pada HP disembunyikan saat bagian checkout terlihat agar tidak menutupi tombol kirim pesanan.

## Verifikasi

- `npm run check`: lint, 48 unit test, parser delapan migrasi SQL, build frontend, dan pemeriksaan sintaks backend lulus.
- `scripts/test-pickup-ui.mjs`: 48 kombinasi lebar/role/status, checkout mobile/desktop, izin GPS diterima/ditolak, COD, pemulihan tracking, respons awal chat yang terlambat, pergantian percakapan, dan Enter ganda lulus. Tes memakai layanan tiruan dan memblokir akses eksternal.
- Build production diuji pada halaman awal dan login di lebar 320, 375, dan 1366 piksel: tidak ada overflow horizontal atau error JavaScript. Ukuran teks, gradient, border, dan padding diperiksa setelah migrasi CSS. Pengunjung tanpa sesi diarahkan dari peta ke login.
- Backend dapat berjalan melalui perintah production dan mode watcher bawaan Node dengan konfigurasi uji lokal. Pemeriksaan kesehatan berhasil; upload dan perubahan status toko tanpa token ditolak 401; origin di luar konfigurasi CORS ditolak 403. Tes ini tidak menghubungi Supabase.
- `npm audit` lengkap pada frontend dan backend tidak melaporkan kerentanan pada saat pemeriksaan, termasuk dependensi development.

## Batas Pemeriksaan

Tailwind 4 menargetkan Safari 16.4+, Chrome 111+, dan Firefox 128+ sesuai [panduan upgrade resmi](https://tailwindcss.com/docs/upgrade-guide). Gunakan browser yang mendukung versi tersebut untuk tampilan yang sesuai. Hasil audit dependensi merupakan hasil pada tanggal pemeriksaan, bukan jaminan tidak akan ada advisory baru.

Pengujian akun asli di Supabase, realtime lintas dua HP, pembayaran nyata, dan status deployment Vercel/Render belum diverifikasi dalam sesi ini. Pengujian browser dengan layanan tiruan bukan UAT pengguna. Pembaruan disiapkan untuk push sesuai permintaan pengguna, tanpa SQL tambahan.
